USTA Tournament UTR Lookup

Beta

Works for publicly accessible USTA tournaments. Some club-level events require login — use the "Paste Player Names" tab instead.

Copy player names from the USTA Players page and paste here — one name per line (e.g. John Smith). Or use the Bookmarklet tab to extract names automatically.

The bookmarklet runs in your browser on the USTA Players page. It reads the rendered player list (even for club-level tournaments that require login) and sends the names here automatically.

Step 1 — Drag this link to your bookmarks bar:

🔗 USTA → UTR Lookup (drag this to your bookmarks bar)

Step 2 — Use it:

  1. Go to a USTA tournament's Players page (log in if needed)
  2. Wait for the player list to load
  3. Click the USTA → UTR Lookup bookmark
  4. This site opens with all player names pre-filled, UTR lookup starts automatically
